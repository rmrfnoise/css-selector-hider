# CSS Selector Hider

按网站配置 CSS 选择器，隐藏不想看到的页面元素。

一个零依赖、零网络请求的 Chrome 扩展（Manifest V3）。

---

## 它做什么

给某个网址配一条规则，规则里列出若干 CSS 选择器。打开匹配的页面时，这些选择器对应的元素会被自动隐藏。

比如：

| URL 模式    | 选择器              | 影响                     |
|:------------|:--------------------|:-------------------------|
| docs.qq.com | .ad-banner          | 隐藏腾讯文档中的广告横幅 |
| zhihu.com   | .RecommendationList | 隐藏知乎的推荐信息       |
| youtube.com | #secondary          | 隐藏 YouTube 右侧边栏    |

用法就是：配一次，以后每次打开那个站点都生效。

---

## 安装

扩展没有上架 Chrome 商店，手动加载即可。

1. 下载或 clone 本仓库到本地任意目录
2. 打开 Chrome，地址栏输入 `chrome://extensions`
3. 打开右上角的 **开发者模式**
4. 点 **加载已解压的扩展程序**，选中本仓库的根目录
5. 扩展栏出现图标，安装完成

首次安装后，点击工具栏图标会打开设置页。

> 修改代码后回到 `chrome://extensions`，点扩展卡片上的刷新按钮即可生效。

## 使用

### 添加一条规则

1. 在设置页底部的输入框里填 **网址片段**，点 **Add**
2. 自动跳到详情页，在表格里逐行填写：
    - **Selector**：CSS 选择器，比如 `.ad-banner`
    - **Note**：备注（可选，只是给自己看的）
3. 改动会实时保存，不需要手动点保存

### 网址怎么填

规则支持三种匹配方式，按填写内容自动判断：

| 你填的 | 匹配方式                       | 例子                          |
|--------|--------------------------------|-------------------------------|
| 含 `/` | 对完整 URL 做子串匹配          | `zhihu.com/question/123`      |
| 含 `:` | 匹配 `host:port`，端口必须相等 | `localhost:8080`              |
| 其余   | 当域名，匹配本身及其所有子域   | `qq.com` 会匹配 `docs.qq.com` |

**例子**（填 `qq.com`）：

- ✅ `https://qq.com/...` — 完全相等
- ✅ `https://docs.qq.com/...` — 子域
- ❌ `https://notqq.com/...` — 后缀不匹配
- ❌ `https://qq.com.evil.site` — 后缀不匹配

开头的 `.` 会被自动去掉，所以填 `.qq.com` 和填 `qq.com` 效果一样。

### 选择器怎么写

就是标准的 CSS 选择器。最省事的办法是从开发者工具里复制：

1. 在目标元素上右键 → **检查**
2. 在 Elements 面板里右键那一行 → **Copy** → **Copy selector**
3. 粘贴到扩展里

一条规则里可以放多个选择器，全部会被合并应用。

### 删除 / 编辑

- 列表页点右侧的 `×` 删整条规则
- 点规则名进详情页，可以改网址、改选择器、逐行删除

### 导入 / 导出

- **Export**：把当前所有规则导出成 JSON 文件
- **Import**：从 JSON 文件导入，会 **覆盖** 当前所有规则

导入前会自动备份最近 3 次的规则到 `chrome.storage.local` 的 `rules_backup` 字段。导入会自动补全缺失的字段、去掉重复的网址和
id。

### 切换语言

设置页和详情页底部都有语言切换按钮，支持中文和英文。语言偏好存在本地，所有页面共享。

## 隐私

- **不发任何网络请求。** 数据只在浏览器的 `chrome.storage.local` 里，不出本机
- **不读 Cookie，不读其他标签页，不注入脚本到页面上下文**
- **权限只有 `storage`**，内容脚本只做一件事：根据规则往页面插一个 `<style>` 标签

## 文件结构

```
.
├── manifest.json     扩展清单
├── background.js     service worker，只负责点击图标打开设置页
├── content.js        内容脚本，读取规则并注入 <style>
├── options.html      规则列表页
├── options.js        列表页逻辑
├── detail.html       规则详情页
├── detail.js         详情页逻辑
└── i18n.js           中英文文案 + 语言切换
```

没有构建步骤，没有依赖，没有打包工具。

## 工作原理

简单说就是三步：

1. **页面加载时**（`document_start`），`content.js` 从 `chrome.storage.local` 读取所有规则
2. 用当前 URL 匹配规则，把所有匹配规则里的选择器合并、去重、过滤非法项
3. 往 `<html>` 里插一个 `<style>` 标签，内容是 `选择器 { display: none !important }`

选择 **注入 `<style>`** 而不是给每个元素写 inline style，好处是：

- 动态新增的节点自动生效，不需要 `MutationObserver`
- 规则被删或被禁用时，移除 `<style>` 就立刻恢复，不用刷新页面
- 页面里没匹配到规则时，扩展完全不修改页面

`content.js` 还监听 `chrome.storage.onChanged`，所以在设置页改完规则，已经打开的页面会 **立即生效**，不用刷新。
